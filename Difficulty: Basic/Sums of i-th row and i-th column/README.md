<h2><a href="https://www.geeksforgeeks.org/problems/sums-of-i-th-row-and-i-th-column3054/1">Sums of i-th row and i-th column</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a 2D integer array <strong>mat[][]</strong> of size <strong>n × m</strong>, check whether for every index i, the sum of the ith row is equal to the sum of the ith column. </span><span style="font-size: 18px;">Return <strong>true</strong> if the condition holds for all valid indices, otherwise return <strong>false</strong>.</span></p>
<p><span style="font-size: 18px;"><strong>Note:</strong> If the matrix is not square (n != m), only compare indices up to min(n, m). For example, if there are 3 rows and 1 column, only compare the 1st row with the 1st column.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[1, 2], [2, 1]]
<strong>Output: </strong>true
<strong>Explanation: </strong></span><span style="font-size: 18px;">Sum of 1st row = 1 + 2 = 3, and Sum of 1st column = 1 + 2 = 3. Similarly, Sum of 2nd row = 2 + 1 = 3, and Sum of 2nd column = 2 + 1 = 3. All corresponding row and column sums are equal.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[5], [0], [0]]
<strong>Output: </strong>true
<strong>Explanation: </strong></span><span style="font-size: 18px;">Only the first row and first column are considered. The sum of the first row is 5, and the sum of the first column is also 5. Both values are equal.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[1, 4, 2], [6, 1, 3]]<br><strong>Output: </strong>false <br><strong>Explaination: </strong></span><span style="font-size: 18px;">Sum of the first row and first column are equal, but the sum of the second row is 10 which is not equal to the sum of the second column which is 5.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 <span style="font-size: 18.6667px;">≤ </span>n, m <span style="font-size: 18.6667px;">≤ </span>10<sup>3&nbsp; &nbsp;<br></sup></span><span style="font-size: 18px;">0 <span style="font-size: 18.6667px;">≤ </span>mat[i][j] <span style="font-size: 18.6667px;">≤ </span>10<sup>3&nbsp;</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Matrix</code>&nbsp;
